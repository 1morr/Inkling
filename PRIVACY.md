# Privacy Policy

**Inkling Notes** is an extension for PowerToys Command Palette that saves notes as Markdown
files on your own computer.

Last updated: 2026-08-23

## What the app collects

**Nothing.** No analytics, no telemetry, no crash reporting, no account system. It never asks
you to sign in.

## What the app sends

**Nothing.** The package declares no network capabilities, so the app cannot make network
requests at all. The developer receives no data from it, ever.

## Where your notes live

Your notes are ordinary `.md` files in a folder you choose (by default, `Inkling` inside your
OneDrive folder). The app reads and writes only:

- that folder and the files in it;
- its own settings file, in the package's local app data;
- an optional diagnostic log in the same place, written only while a file named
  `diagnostic.on` exists there. It stays on your machine.

Deleting a note sends the file to the Recycle Bin. If your notes folder sits on a cloud drive,
that drive's own terms apply to the files — Inkling contains no sync code.

## Failure messages

When something fails, the app writes a short message to Command Palette's own log, which stays
on your machine. Those messages deliberately exclude file paths, note titles, and anything you
typed.

## Children

The app is not directed at children and collects no information from anyone.

## Changes

Any change to this policy is committed to this repository, and this page always shows the
current version.
